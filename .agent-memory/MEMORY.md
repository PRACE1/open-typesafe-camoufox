# Shared run lessons (bounded excerpt injected into every Jev state packet)

- Google SERP: result links often carry weak labels; prefer entries whose text names the outcome. The search box is never the answer twice.
- A click-opened popup dies with its opener in this build — adopt via +newtab first, never close the opener of the live tab.
- "Looking for results in English?" is a language banner, not loading; long pages with real results count as settled.
- Typing into a filled box replaces (clear-before-type); retyping identical text is a loop — move on.
- Confidence below 0.4 idles; three identical click/type targets force wait; two doubt no-ops stop the run.
- Passwords only ever come from {ENV} placeholders in the task; the writer always declines credentials.
- `wait` is patience for loading screens, not indecision; `done` needs the concrete outcome quoted from PAGE TEXT.
